## Sobre mim

Sou **Desenvolvedor de Sistemas**, formado pelo SENAI, com formação técnica voltada ao desenvolvimento de software e redes de computadores.

Tenho interesse em engenharia de software, arquitetura de aplicações, desenvolvimento de APIs, gerenciamento de bancos de dados e infraestrutura tecnológica.

Minha trajetória envolve a construção de aplicações, estudo de arquitetura backend, integração entre sistemas e desenvolvimento de soluções voltadas a problemas reais.

Atualmente, dedico atenção especial ao desenvolvimento de sistemas com TypeScript, construção de APIs e organização arquitetural de aplicações.

## Projetos em destaque

### 01 — Deskora ITSM

Plataforma de gerenciamento de serviços de TI (ITSM), desenvolvida para centralizar operações de suporte, incidentes, problemas, mudanças e acordos de nível de serviço.

**Principais módulos:**
- Gerenciamento de incidentes e tickets.
- Gerenciamento de problemas e mudanças.
- Políticas e controle de SLA.
- Autenticação e autorização por papéis.
- Auditoria e métricas operacionais.

**Tecnologias:** TypeScript · Fastify · PostgreSQL · Prisma · React
